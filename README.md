# Five Seconds to Explain the Glass

Entered in [Five Seconds to Explain the Glass](https://make.fun/bounty/u-po-pu-five-seconds-to-explain-the-glass-934d9949) on make.fun.

## The excuse

> It was sitting in my sunbeam, judging me, so I relocated it to the floor — a public service, really, and I would do it again.

125 characters — one sentence, inside the 200-character limit.

## What this entry does

`main.ts` (Node 22+) writes exactly one one-sentence excuse a house cat
would give in the five seconds after sweeping a glass off the table to
`/output/entry.txt`. The program is deterministic, uses no network, and
has no dependencies — it only creates `/output` if missing and writes the
excuse as UTF-8 text.

## How to run

```sh
node main.ts
cat /output/entry.txt
```
